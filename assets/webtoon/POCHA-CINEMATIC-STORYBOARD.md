# 퇴근길 포장마차 — 시네마틱 웹툰 스토리보드

## 적용 범위
- 이번 콘텐츠 전용 풀이자: 서도윤. 다른 콘텐츠의 공통 캐릭터로 사용하지 않는다.
- 슬림한 성인 남성, 짙은 웨이브 헤어, 얇은 안경, 검정 셔츠, 차분하고 지적인 인상.
- 고급 2D K-웹툰, 딥 네이비/다크 브라운/절제된 웜 골드, 밝은 파스텔·과장된 아이돌 스타일 금지.
- 컷마다 독립된 장면, 화면 속 글자는 생성하지 않고 접근 가능한 HTML 레이어로 분리.
- 이 파일은 연출 기획안이다. 실제 이미지 에셋 교체 및 운영 반영은 별도 검증 후 수행.

## 무료 도입 / 유료 이야기
- 01–06: 무료 도입에서 현실적 고민, 장소, 풀이자 등장까지.
- 07–20: 유료 이야기에서 개인별 사주 해석과 행동 지침을 자연스럽게 연결.
