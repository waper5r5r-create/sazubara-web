그림체 두 가지를 섞어 써요.
- **금비 장면과 장부 카드:** 3차 시험 금비 그림체(2D 게임 캐릭터 일러스트). 기준 그림 [source/gumbi-face-ref.webp](source/gumbi-face-ref.webp), [source/gumbi-scene-test.webp](source/gumbi-scene-test.webp)
- **현실 장면(주인공):** 진한 선의 한국 웹툰 컷. 기준 그림 [source/hero-f-ref.webp](source/hero-f-ref.webp), [source/hero-m-ref.webp](source/hero-m-ref.webp)

세 묶음은 **각각 새 채팅창**에서 해요. 그림체가 섞이지 않게요.
끊기면 "계속", 마음에 안 들면 "G3 다시"처럼 번호로 말해요. 다 되면 묶음별로 다운로드 폴더에 받아두고 알려주세요. 파일 이름에 번호가 들어가면 제가 맞추기 쉬워요.

## 묶음 A — 금비 시트와 장면 11장

첨부: **금비 기준 그림 두 장** (다운로드 폴더의 「장부를 든 금비의 두 초상-1.png」, 「저울과 동전을 살피는 금비-2.png」)

```
첨부한 두 그림의 인물이 "금비"예요. 사주 서비스 "재물 사주"의 안내 캐릭터예요. 아래 목록을 A1부터 G9까지 순서대로, 멈추거나 내 확인을 기다리지 말고 쭉 이어서 그려주세요. 답변이 끊기면 내가 "계속"이라고 할 때 이어서 그려주세요. 그림마다 번호만 짧게 적어주세요.

[금비 — 첨부 그림과 똑같이]
얼굴형, 눈매, 눈썹, 코, 입, 어깨 길이 밤색 단발과 일자 앞머리, 얇은 금테 동그란 안경, 소매를 걷은 크림 블라우스, 금단추가 달린 여유 있는 핏의 검은 조끼, 작은 빨간 리본 타이, 허리의 가죽 동전 주머니는 첨부 그림과 완전히 같게. 귀나 꼬리 같은 동물 요소는 없음. 계산할 때 한쪽 눈썹을 올리고, 기분 좋으면 펜을 손가락으로 돌리는 버릇.

[그림체 — 첨부 그림과 같게]
2D 게임 캐릭터 일러스트. 얇고 일정한 윤곽선, 명암 2~3단계, 머리카락은 큰 덩어리와 광택 한두 군데. 얼굴·손·핵심 소품만 자세히, 옷과 배경은 간결하게, 배경은 인물보다 채도를 낮게. 반짝이·빛 번짐·떠다니는 입자는 넣지 않기. 그림 안에 글자, 숫자, 말풍선, 로고, 워터마크는 넣지 않기. 장부·영수증·달력에도 글자 대신 선과 도형만.

[장소 — 금빛 저울방]
낮 시간의 밝은 작은 환전소. 원목 계산대, 황동 저울, 뒤쪽 선반에 동전 단지 몇 개와 두꺼운 장부들. 장식은 적게.

[연출]
매 컷마다 금비가 무언가를 하는 순간으로. 카메라를 보며 웃기만 하는 화보 컷은 피하기. 컷마다 거리와 각도를 바꾸기.

[그림 목록]
A1. 전신 시트 (3:2 가로) — 밝은 회색 배경. 정면 전신, 옆면 전신, 뒷면 전신. 장부를 옆구리에 낌.
A2. 표정 시트 (3:2 가로) — 밝은 회색 배경, 가슴 위 2줄 4칸, 칸 사이 여백 넉넉히. ① 장난스러운 미소 ② 한쪽 눈썹을 올리고 계산하는 얼굴 ③ 눈이 동그래진 놀람 ④ 걱정스럽게 눈썹을 모은 얼굴 ⑤ 검지를 세우고 "잠깐!" 하는 단호한 얼굴 ⑥ 눈을 감고 환하게 웃음 ⑦ 펜 끝을 턱에 대고 생각 ⑧ 장부를 펼쳐 한 줄을 가리키며 설명.
G1. cover (1:1) — 가슴 위. 장부를 옆구리에 끼고, 엄지로 동전 하나를 위로 튕기는 순간. 동전을 눈으로 좇는 장난스러운 미소.
G2. greeting (4:5 세로) — 환전소 문을 열고 고개를 내밀며 "어서 와요" 하듯 손짓하는 상반신. 문틈으로 계산대가 살짝 보임.
G3. scale (4:5 세로) — 계산대 위 황동 저울 양쪽 접시에 동전을 올려 균형을 보는 미디엄 숏. 저울이 한쪽으로 살짝 기울었고, 금비는 한쪽 눈썹을 올림.
G4. ledger-open (4:5 세로) — 두꺼운 장부를 양손으로 펼쳐 이쪽(보는 사람)에게 보여주는 허리 위. 페이지에는 칸과 선만.
G5. leak (1:1) — 클로즈업. 장부의 한 칸을 검지로 콕 짚으며 "잠깐!" 하는 단호한 얼굴.
G6. timeline (4:5 세로) — 계산대 위에 펼친 긴 연표 종이(칸만 있음)에 동전 세 개를 골라 올려놓는 손과 금비의 얼굴. 위에서 내려다보는 각도.
G7. receipt (1:1) — 가슴 위. 길쭉한 영수증 종이(선만)를 손가락에 끼워 이쪽으로 내밀며 엄지를 세우는 모습.
G8. detail (4:5 세로) — 계산대 뒤 높은 선반에서 두꺼운 장부를 꺼내며 뒤돌아보는 모습. "자세한 건 여기 있어요" 하는 표정.
G9. farewell (4:5 세로) — 환전소 문 앞에서 동전 주머니를 흔들며 배웅하는 전신. 맑은 낮.

A1부터 그려주세요.
```

## 묶음 B — 현실 장면 (남녀 두 벌 + 공용) 18장

첨부: **주인공 기준 그림 두 장** (다운로드 폴더의 「택배 상자 앞, 망설이는 오후-1.png」, 「소파 끝에서 택배 구매 고민-2.png」)

```
첨부한 두 그림의 그림체와 두 주인공(여자 주인공, 남자 주인공)을 그대로 유지해서, 사주 서비스 "재물 사주"의 현실 장면을 그려주세요. 아래 목록을 S1F부터 S10까지 순서대로, 멈추거나 내 확인을 기다리지 말고 쭉 이어서 그려주세요. 답변이 끊기면 내가 "계속"이라고 할 때 이어서 그려주세요. 그림마다 번호만 짧게 적어주세요.

[그림체 — 첨부 그림과 같게, 한 단계 더 진하게]
요즘 한국 액션·일상 웹툰의 한 컷. 바깥 윤곽선은 굵고 진한 검정, 안쪽 선은 가늘게. 그림자는 경계가 또렷하고 각진 한 단계로, 첨부 그림보다 조금 더 진하게. 부드러운 그라데이션과 빛 번짐은 쓰지 않음. 실제 사람에 가까운 비율, 표정은 확실하게. 배경은 선과 평평한 색으로 단순하게. 전체적으로 밝은 장면(크림·하늘색 위주). 그림 안에 글자, 숫자, 말풍선, 로고, 워터마크는 넣지 않기. 휴대폰·모니터·통장·서류 화면에는 글자 대신 선과 도형만.

[주인공 — 첨부 그림과 같게]
여자 주인공: 20대 후반 직장인, 어깨 아래 긴 생머리를 낮게 묶음, 둥근 얼굴에 차분한 인상, 크림색 니트와 청바지(출근 장면은 베이지 재킷).
남자 주인공: 20대 후반 직장인, 짧은 흑발, 눈매가 순한 인상, 회색 후드티와 면바지(출근 장면은 남색 재킷).

[규칙]
- 비율은 모두 4:5 세로.
- 번호 끝이 F면 여자 주인공, M이면 남자 주인공. 같은 번호의 F와 M은 장면·구도·배경을 똑같이 하고 사람만 바꾸기.
- 인물이 소품에 가려지지 않게 배치하기(발·손이 상자 같은 물건 뒤로 사라지지 않게).

[그림 목록]
S1F / S1M. 월급날 — 퇴근길 지하철역 계단에서 휴대폰 알림을 보고 눈이 커지며 입꼬리가 올라가는 순간. 미디엄 숏.
S2F / S2M. 충동구매 — 주말 오후 밝은 방, 소파에 앉아 휴대폰을 보며 결제를 할까 말까 고민. 입술을 깨물고 눈썹을 모음. 택배 상자 두세 개는 인물 옆 바닥에, 발을 가리지 않게.
S3F / S3M. 투자 고민 — 카페 창가에서 노트북 화면의 오르내리는 선 그래프(글자 없음)를 보며 턱을 괴고 고민하는 옆모습.
S4F / S4M. 돈 빌려달라는 친구 — 카페 테이블 맞은편 친구가 두 손을 모으고 부탁하는 중, 주인공은 난감하게 웃으며 뒷머리를 긁음. 친구는 뒷모습 위주.
S5F / S5M. 동업 제안 — 사무실 회의 테이블에서 친구가 계획서(선과 도형만)를 펼쳐 보이고, 주인공은 팔짱을 끼고 진지하게 듣는 장면.
S6F / S6M. 부업 — 퇴근 후 저녁, 책상 스탠드 아래 노트북으로 무언가를 만들며 집중한 얼굴. 밝은 실내등.
S7F / S7M. 돈이 들어오는 해 — 회사에서 상사에게 두툼한 봉투를 받으며 놀라 웃는 장면. 상사는 실루엣이나 뒷모습.
S8F / S8M. 가계부 쓰기 — 아침 식탁에서 커피를 옆에 두고 작은 가계부 노트(칸만)에 펜으로 적으며 뿌듯한 표정.
S9. 저축(공용) — 손 클로즈업. 꽉 찬 돼지저금통에 동전을 하나 더 넣는 손. 밝은 창가.
S10. 큰 지출(공용) — 손 클로즈업. 계약서(선만) 위에 도장을 찍으려다 멈칫한 손, 옆에 열쇠 꾸러미.

## 묶음 C — 재물 장부 카드 10장 + 오행별 장면 15장

첨부: 금비 기준 그림 한 장 (그림체 맞추기용, 「저울과 동전을 살피는 금비-2.png」)

```
첨부한 그림과 같은 그림체(2D 게임 캐릭터 일러스트, 얇은 윤곽선, 명암 2~3단계)로, 사주 서비스 "재물 사주"에 들어갈 그림 25장을 그려주세요. 첨부 그림의 인물은 그리지 않아요. 아래 목록을 K1부터 V15까지 순서대로, 멈추거나 내 확인을 기다리지 말고 쭉 이어서 그려주세요. 답변이 끊기면 내가 "계속"이라고 할 때 이어서 그려주세요. 그림마다 번호만 짧게 적어주세요.

[공통]
그림 안에 글자, 숫자, 말풍선, 로고, 워터마크는 넣지 않기. 화면·서류·통장에는 글자 대신 선과 도형만. 반짝이·빛 번짐·떠다니는 입자는 넣지 않기. 그림 가장자리에 테두리나 프레임 넣지 않기.

[K1~K10 · 재물 장부 카드 — 공통]
3:4 세로. 사람은 나오지 않는 정물 카드 그림. 가운데에 돈과 관련된 물건 하나를 크게, 배경은 크림·연한 금색의 단순한 그라데이션. 10장 모두 같은 구도와 배경 톤을 유지하고 물건만 바꾸기.
K1. 씨앗 금화 — 작은 나무 새싹 뿌리에 금화 몇 개가 열매처럼 달려 있음.
K2. 덩굴 동전 — 덩굴줄기를 따라 동전이 사슬처럼 이어짐.
K3. 햇살 금화 — 햇빛을 받아 밝게 빛나는 금화 더미(빛 번짐 효과 없이 색으로만 밝게).
K4. 등불 금고 — 작은 등불 아래 놓인 아담한 나무 금고.
K5. 산 금괴 — 산처럼 차곡차곡 쌓인 금괴.
K6. 곳간 자루 — 곡식 자루 입구로 동전이 쏟아져 나옴.
K7. 무쇠 금고 — 단단한 무쇠 금고, 굵은 자물쇠.
K8. 보석함 — 뚜껑이 살짝 열린 작은 보석함.
K9. 금화 나룻배 — 잔잔한 물 위의 작은 나룻배에 금화가 실려 있음.
K10. 빗물 항아리 — 처마 아래 항아리에 빗물처럼 동전이 고임.

[V1~V15 · 오행별 장면 — 공통]
4:5 세로. 사람은 손과 소매만 나오게(성별이 드러나지 않게). 같은 상황을 성격이 다른 다섯 사람이 다르게 행동하는 장면이라, 손과 물건만으로 차이가 한눈에 보이게. 밝은 실내.
V1. 돈 쓸 때 · 목 — 온라인 강의와 책 결제 화면(도형만)을 띄운 노트북 위 손.
V2. 돈 쓸 때 · 화 — 식당 계산대에 카드를 먼저 쭉 내미는 손, 뒤로 친구들 손이 보임.
V3. 돈 쓸 때 · 토 — 마트 카트에 휴지와 생필품을 가득 담는 손.
V4. 돈 쓸 때 · 금 — 같은 물건 두 개를 양손에 들고 비교하는 손.
V5. 돈 쓸 때 · 수 — 휴대폰으로 긴 후기 목록(선만)을 스크롤하는 손, 옆에 메모.
V6. 돈 모을 때 · 목 — 목표별로 이름표 대신 색이 다른 저금 봉투 여러 개를 나눠 담는 손.
V7. 돈 모을 때 · 화 — 달력에 "모은 날"을 스티커로 신나게 붙여나가는 손.
V8. 돈 모을 때 · 토 — 꽉 찬 돼지저금통을 두 손으로 소중하게 감싸 쥔 손.
V9. 돈 모을 때 · 금 — 칸이 정확하게 나뉜 가계부에 자로 줄을 긋는 손.
V10. 돈 모을 때 · 수 — 휴대폰 자동이체 설정 화면(도형만)을 누르는 손, 옆에 따뜻한 차.
V11. 돈 불릴 때 · 목 — 새 사업 아이디어를 노트에 그림과 화살표로 그리는 손.
V12. 돈 불릴 때 · 화 — 가파르게 오르는 그래프(선만) 화면을 보며 휴대폰을 꽉 쥔 손.
