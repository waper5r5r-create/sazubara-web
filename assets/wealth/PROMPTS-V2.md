# 재물 사주 — 현실 장면(주인공) 그림체 시험

정리 (2026-10-25):
- **금비는 3차 시험 그대로 확정.** 그림체(2D 게임 캐릭터 일러스트)와 얼굴 모두 유지. 기준 그림: [source/gumbi-face-ref.webp](source/gumbi-face-ref.webp)
- **진한 선과 또렷한 명암의 웹툰 컷 그림체는 현실 장면(주인공)에만** 쓴다.
- 주인공은 성별을 숨기지 않고, 사용자가 입력한 성별에 맞춰 여자 주인공·남자 주인공 장면을 따로 만든다. 손이나 물건만 나오는 컷은 한 벌로 같이 쓴다.
- 작가 이름은 쓰지 않고 그림의 특징으로 적는다.

## 시험 2장 (새 채팅창, 첨부 없이)

```
사주 서비스의 웹툰형 화면에 들어갈 "현실 장면" 그림 2장을 그려주세요. 2장을 다 그리면 멈춰주세요.

[그림체 — 2장 모두 같게]
요즘 한국 액션·일상 웹툰의 한 컷 같은 그림체.
- 선: 바깥 윤곽선은 굵고 진한 검정(붓으로 그은 듯한 굵은 선), 안쪽 선은 가늘게.
- 명암: 경계가 칼로 자른 듯 또렷한 진한 그림자 한 단계. 밝은 곳과 어두운 곳의 대비를 강하게. 부드러운 그라데이션과 빛 번짐은 쓰지 않음.
- 얼굴: 실제 사람에 가까운 비율, 턱선과 광대가 드러나는 또렷한 구조, 과하게 크지 않은 날렵한 눈. 표정은 확실하게 읽히게.
- 머리카락: 끝이 뾰족한 큰 덩어리, 각진 하이라이트 한두 개.
- 배경: 선과 평평한 색으로 단순하게, 원근은 분명하게.
- 색: 밝은 장면이라 크림·하늘색 위주로 밝게.
- 그림 안에 글자, 숫자, 말풍선, 로고, 워터마크는 넣지 않기. 휴대폰 화면 내용은 그리지 않기.

[장면 — 2장 같은 장면, 같은 구도]
주말 오후 햇살이 드는 밝은 방. 소파 끝에 걸터앉아 휴대폰을 보며 결제를 할까 말까 고민하는 순간. 입술을 살짝 깨물고 눈썹을 모은 표정. 발치에 뜯지 않은 택배 상자 두세 개. 인물이 화면의 절반쯤 차지하는 미디엄 숏, 살짝 옆에서 본 각도.

1장: 여자 주인공 — 20대 후반 직장인. 어깨 아래 긴 생머리를 낮게 묶음, 둥근 얼굴에 차분한 인상, 크림색 니트와 청바지.
2장: 남자 주인공 — 20대 후반 직장인. 짧은 흑발, 눈매가 순한 인상, 회색 후드티와 면바지.

1장부터 그려주세요.
```
