# 재물 사주 — 금빛 저울방의 환전상 "금비" · 그림체 시험

## 3차 시험 (2026-10-25) — 더 예쁜 사람 얼굴로, 휴대폰 장면은 새로 짧게

2차 결과: 사람 버전과 여유 있는 조끼 핏은 좋음. 그런데 덧니가 송곳니처럼 보이고, 눈썹이 굵고, 전체 인상이 아직 사람보다 캐릭터 같음. 휴대폰 장면은 손·머리·원근이 엉켜서 새로 그리기로 함.

**같은 ChatGPT 채팅창에 이어서** 아래를 보내요.

```
그림체와 옷, 소품, 장소는 지금 그대로 좋아요. 금비 얼굴만 더 예쁜 사람 얼굴로 다듬어서 T1, T2를 다시 그려주세요.

- 덧니는 빼고 고른 치아로. 웃을 때 입꼬리가 한쪽만 조금 더 올라가는 장난스러운 미소.
- 눈썹은 가늘고 자연스러운 일자 눈썹으로. 계산할 때 한쪽 눈썹을 살짝 올리는 버릇은 유지.
- 눈은 지금처럼 동그란 눈매를 유지하되, 쌍꺼풀이 얇게 보이고 속눈썹이 또렷한 맑은 눈.
- 코는 작고 콧대가 살짝 보이는 자연스러운 코.
- 얼굴형은 갸름한 달걀형에 볼만 살짝 통통하게.
- 피부는 맑은 톤, 볼에 아주 옅은 홍조.
- 금테 동그란 안경, 어깨 길이 단발, 일자 앞머리는 그대로.
- 과하게 꾸민 화보 얼굴이 아니라, 똑똑하고 귀여운 20대 후반 여성의 자연스러운 얼굴로.
```

휴대폰 장면(T3)은 **새 채팅창**에서 따로, 짧게 그려요. 같은 그림체를 맞추기 위해 위에서 새로 나온 T2(환전소 장면)를 첨부해요.

```
첨부한 그림과 같은 그림체로 한 장만 그려주세요. 3:2 가로.

밤, 어두운 방. 침대 끝에 걸터앉은 사람을 옆에서 본 모습. 고개를 숙이고 두 손으로 휴대폰을 보고 있고, 휴대폰 불빛이 얼굴 아래쪽만 살짝 비춤. 발치에 뜯지 않은 택배 상자 두 개.
사람은 짧은 머리에 헐렁한 후드티, 성별이 드러나지 않게. 표정은 보이지 않게.
휴대폰 화면 내용은 그리지 않기. 글자 없음.
```

## 2차 시험 (2026-10-25) — 사람으로 바꾸고, 휴대폰 장면 다시

1차 시험 결과: 그림체 방향은 좋음(AI 느낌이 크게 줄었음). 바꿀 점은 두 가지.
- 금비를 너구리 수인이 아니라 사람으로(귀와 꼬리 빼기)
- 휴대폰 장면이 쇼핑앱 화면을 그대로 그린 듯해서 AI 티가 남

**1차 시험을 했던 ChatGPT 채팅창에 이어서** 아래를 보내요(그림체가 그대로 이어져요).

```
좋아요, 그림체는 이 방향으로 유지해주세요. 아래 두 가지만 바꿔서 T1~T3를 다시 그려주세요.

1) 금비를 사람으로 바꿔주세요.
- 너구리 귀와 꼬리는 그리지 않기. 눈 아래 너구리 무늬 같은 그늘도 빼기.
- 얼굴, 단발머리, 금테 동그란 안경, 덧니, 짧고 도톰한 눈썹, 한쪽 눈썹을 올리는 버릇, 크림 블라우스·검은 조끼·빨간 리본 타이·동전 주머니는 그대로.
- 조끼는 몸에 붙지 않는 단정하고 여유 있는 핏으로. 가슴이나 몸매가 강조되지 않게.
- 기분 좋을 때는 꼬리 대신 손가락으로 펜을 돌리는 습관.

2) T3 휴대폰 장면은 화면을 그리는 대신 "망설이는 순간"을 보여주세요.
- 쇼핑앱 화면 디자인(상품 목록, 버튼, 장바구니 아이콘)을 정면으로 자세히 그리지 않기.
- 휴대폰은 비스듬한 각도로 들려 있고, 화면은 빛이 나는 흐릿한 색 덩어리 정도로만 보이게.
- 대신 장면으로 상황을 보여주기: 어두운 방, 침대에 엎드린 사람의 손과 휴대폰 불빛, 방 한쪽 구석에 아직 뜯지 않은 택배 상자 두세 개가 쌓여 있음. 엄지는 화면 위에서 멈칫.
- 사람은 손과 소매, 뒷머리 일부만. 성별이 드러나지 않게 짧은 머리.
- 휴대폰 불빛 하나만 밝고 나머지는 차가운 남색 어둠.

T1부터 다시 그려주세요.
```

## 1차 시험 (참고용)

```
사주 서비스 "재물 사주"의 안내 캐릭터 "금비"를 처음 그려볼 거예요. 그림 3장을 순서대로 그려주세요. 3장을 다 그리면 멈춰주세요.

[그림체 — 3장 모두 같게]
2D 게임 캐릭터 일러스트. 수집형 게임의 캐릭터 카드처럼 완성도 있게, 하지만 화려하게 꾸미지는 않기.
- 윤곽선: 얇고 일정한 선. 얼굴과 손은 조금 더 또렷하게.
- 채색: 명암은 2~3단계로 나눈 채색이 중심. 얼굴에만 볼 홍조 정도의 부드러운 그라데이션.
- 머리카락: 큰 덩어리 몇 개로 나눠 그리고, 잔선은 끝부분에 조금만. 광택은 한두 군데만.
- 묘사의 강약: 얼굴·손·핵심 소품만 자세히, 옷 주름과 배경은 형태만 간결하게. 배경은 인물보다 채도와 대비를 낮게.
- 하지 않을 것: 머리카락 전체의 촘촘한 잔선과 번들거리는 광택, 매끈한 플라스틱 같은 피부, 과한 옷 주름, 화면을 채운 장식, 이유 없는 반짝임·빛 번짐·떠다니는 입자, 카메라를 보며 짓는 똑같은 미소.
- 그림 안에 글자, 숫자, 로고, 말풍선, 워터마크는 넣지 않기.

(금비 설정·장소·T1~T3 목록은 2차 시험에서 바뀐 부분 외에는 1차와 같음)
```
